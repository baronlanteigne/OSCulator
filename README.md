# OSCulator — plugin only

This branch is **just the OSCulator plugin**, with no demo project. Clone it straight
into your project's `Plugins/` folder and build:

```bash
git clone -b plugin https://github.com/baronlanteigne/OSCulator.git Plugins/OSCulator
```

New to OSCulator? The [`main`](https://github.com/baronlanteigne/OSCulator) branch is a
ready-to-run demo project that uses this plugin, with example content and a TouchOSC
template. Documentation is in [`Docs/`](Docs/).
