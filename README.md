# UE OSCulator
UE OSCulator is a OSC + MIDI plugin for Unreal Engine designed to use simplify bi-directional interaction between multiple tools.

## Key features
- Remotely run a function (event) in any actor in your project by sending an OSC or MIDI message without building your own parser or manager.
- Enable tools that simplify creating and send OSC messages, MIDI notes and CC from Unreal.
